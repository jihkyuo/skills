# 라운드 규칙 — 변형이 «다른 답»이 되게 하는 조건

워커와 코디네이터가 함께 읽는다. 발산 라운드와 피드백 라운드 모두에 적용된다.

## 1. 축 하나

변형은 **이름 붙인 주축 하나**에서만 갈라진다. 주축의 후보:

| 축 | 무엇이 달라지나 |
|---|---|
| 구조 | 묶음·순서·열 개수·무엇이 접히나 |
| 정보 위계 | 무엇이 먼저 읽히고 무엇이 뒤로 물러나나 |
| 밀도 | 간격 눈금·클릭 영역·한 화면에 담기는 양 |
| 강조 | 채움 색이 어디에 가고 무엇이 물러나나 |
| 활자 | 단계·굵기 대비·행 길이 |
| 목소리 | 라벨·어조·문구의 양 |
| 상호작용 모델 | 클릭·호버·드래그·인라인 편집 중 무엇으로 조작하나 |

부차 선택은 주축에서 **따라온다**. 밀도 높은 변형이 활자 단계를 한 단 줄이는 것은 일관성이지 두 번째 축이 아니다. 모든 축을 동시에 바꾸면 «어느 것이 통했는지» 못 배우고, 다음 라운드가 0에서 시작한다.

발산 라운드의 축은 «논제»(문제를 푸는 방식)다. 피드백 라운드의 축은 사용자가 기운 방향 안의 한 자리다.

## 2. 이름은 방향을 말한다

«조용한», «한 장», «장부», «대조»처럼 방향이 읽히는 이름을 쓴다. «옵션 A/B/C», «변형 1/2/3»은 금지. 이름을 지을 수 없으면 축이 없는 것이다.

## 3. 바닥선은 동일하고 축이 아니다

모든 변형이 같은 바닥선(`craft-floor.md` Verify 9항 + 씨드 계약)을 넘는다. 바닥선은 라운드마다 늘지 않는다. **어떤 방향이 바닥선을 깨야만 성립하면 그 방향을 버린다**, 바닥선을 낮추지 않는다. 겉보기에 이기고 바닥선에서 지는 변형은 후보가 아니라 예쁜 표면을 가진 결함이다.

## 4. 실제 크롬 안, 실제 데이터, 실제 개수

빈 라우트는 모든 변형을 괜찮아 보이게 한다. 실제 사이드바·헤더(씨드의 크롬 블록), 실제 도메인 문구, 페이지가 실제로 담을 개수(빈 상태·상한·긴 문자열 포함)로 짓는다. 로렘 입숨과 3행짜리 목록은 모든 구조를 좋아 보이게 한다.

## 5. 한 번에 한 변형, 전체 크기

썸네일은 간격과 스케일을 왜곡하고, 간격이 보통 고르는 대상이다. compare 화면은 한 슬롯을 전체 크기로 보이고 키로 전환한다(`assets/compare-template.html`).

## 6. 헤드라인 교환 테스트

두 변형의 제목 텍스트를 서로 바꿔 끼워도 아무도 눈치 못 채면 둘은 너무 비슷하다. 하나를 주축의 다른 위치로 옮기거나 버린다. 텍스트 유사도 수치는 공유 계약 마크업 때문에 무의미하고, 이 테스트가 정본이다.

## 7. 다음 라운드는 같은 하네스, 같은 작가

한 번 더 돌려 달라는 요청에는 **하네스와 작가를 유지**하고, 사용자가 기운 방향 주변에서 새 위치를 잡는다. 작가 세션이 없으면 재수화한다(SKILL.md Phase 4). 낯선 워커에게 사본을 주는 것은 «다음 라운드»가 아니라 재작성이다.

## 8. 코디는 선호를 표시하지 않는다

수령 보고와 compare 안내에는 변형마다 «맞는 때 / 비용»만 적는다. 직접 물으면 «얼마나 자주 보는 화면인가»와 제품의 성격에서 답하고, 만들기 즐거웠던 쪽에서 답하지 않는다.

## 9. 개수

발산 라운드는 3 기본, 5 최대. 피드백 라운드는 3 이하. 다섯을 넘으면 아무도 비교하지 않고 스크롤한다.

## 10. 승격 하나, 나머지는 보존

확정안 하나를 정식 구현 라운드로 넘긴다. 탈락 변형은 지우지 않고 `_archive/`(또는 브랜치)에 남긴다. 시안 코드는 프로토타입 조건(테스트 없음·에러 처리 최소)에서 쓰인 것이라 그대로 프로덕션에 넣지 않는다.

## 이 파일이 잡는 실수

| 실수 | 고침 |
|---|---|
| 변형이 색·문구만 다르다 | 하나를 주축의 다른 위치로 옮기거나 잘라낸다 |
| 모든 축이 한꺼번에 변한다 | 하나만 변하게, 나머지는 따라오게 |
| 빈 화면에서 판단했다 | 크롬 블록과 실제 데이터로 다시 |
| 가장 대담한 변형이 키보드·포커스를 건너뛴다 | 바닥선을 넘기거나 그 방향을 버린다 |
| 표에 코디의 선호가 적혀 있다 | 비용과 맞는 때만 적는다 |
| 다음 라운드를 새 워커 + 사본으로 돌렸다 | 같은 작가, 같은 하네스 |
