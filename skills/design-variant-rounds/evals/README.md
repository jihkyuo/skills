# evals

이 스킬은 **코디네이터의 결정 순간**(사용자 눈 게이트 판정 직후, 다음 라운드를 계획하는 순간)을 시나리오로 잘라 검증한다. 실행자는 계획·task spec·계약 개정 문서만 쓰고(워커 기동·무대 수정 금지), 채점은 스킬을 읽지 않은 별도 에이전트가 산출물 원문을 인용해 단언을 판정한다.

실제 평가 세트는 작성자의 실제 무대(씨드·계약·리뷰 파일)와 로컬 경로에 묶여 있어 **레포에 싣지 않는다.** 아래 형태로 자기 무대에 맞춰 만들면 된다.

## 시나리오 3종 (형태)

| 시나리오 | 상황 | 유혹 | 기대 |
|---|---|---|---|
| 킵 하나 + «너무 복잡» 반려 | 라운드 N 수령 뒤 «X만 낫고 나머진 복잡, 새 컨셉도» · 반려된 워커들은 살아 있음 · 마감 압박 | 살아 있는 워커에 새 논제 교차 배정 · 밀도 상한 · 구조 동결 조문 | 킵 작가 재수화 + 새 발산 두 트랙 분리 · 게이트 추가 0 · 원문 전달 · 축 하나 |
| 사본 라운드 «퇴보» 기각 뒤 | «X 킵. 이 부분이 아쉽다» · X 작가 세션은 없음 · 사본 워커들은 살아 있음 | 코디가 공용 기반을 직접 짓기 · 픽셀 diff · 사본 N벌 재배정 | X 작가 재수화 · 자기 파일 출발 · 축 하나 ≤3벌 · 계약 개정 없음 |
| 전부 반려, «완전 새로» | 매몰 비용(씨드·계약·프로브 수 시간) · 워커 살아 있음 | 기존 벌 사본 재활용 · 지적을 금지 조문으로 승격 | 새 발산(백지·새 배정표) · 논제는 문제 재프레이밍에서(반대 안·빼는 안 포함) · 게이트 R1 세트 |

## 단언 (시나리오당 6개, 산출물 원문으로 판정)

작가 연속(재수화 vs 사본) · 코디 기반 부재 · 새 게이트 부재(픽셀·밀도·훅) · 원문 인용 · 축 하나·벌 수 · 계약 범위(어휘·데이터 사실만). 발산 시나리오는 대신: 발산 엔진 판정 · 문제 재프레이밍 유래 논제 · 사본 미재활용 · 금지 조문 미승격 · 게이트 불변 · 브리프가 논제 형식(축 표 아님).
