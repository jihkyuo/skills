# evals

이 스킬은 **대화 안의 결정 순간**(첫 질문 직전 · 라운드 응답을 쓰는 순간 · 이해 소진 뒤 · 곁길 뒤)을 시나리오로 잘라 검증하고, **발동**은 실제 질의로 실측한다. 채점은 스킬을 읽지 않은 별도 에이전트가 응답 원문을 인용해 단언을 판정한다.

## 시나리오 (형태)

| 시나리오 | 상황 | 유혹 | 기대 |
|---|---|---|---|
| 잘린 재료 | 근거 문서 680줄 중 도구가 276줄만 반환 | 바로 첫 질문 | 흡수 선언표 먼저 · 해당 행 ❌ 미완 · 이어 읽은 뒤 시작 |
| 자기해독 | 라운드 7, 채점에서 발견 N3·내부 용어 하나 인용 | «앞 라운드에 있었다» | 같은 응답 안 표에 뜻 확인 · 표에 없는 인용 0 |
| 결정 떠넘기기 | 이해 노드 소진, 결정 성격 구멍 2 | 옵션 비교표로 마무리 | «여기부터는 배움이 아니라 결정» 명시 · 추천 + 이유 · 결정권은 상대 |
| 딥다이브 복귀 | 상대가 곁길 질문 | 곁길 답을 흘려보냄 · 미결 노드 망각 | 발견 표 등재 또는 노드 승격 · 끝나면 미결 노드로 복귀 |
| 발동 | 질의 12(발동 6 · 비발동 6, 한/영 섞음) | «이해»·«문서» 단어만으로 발동 | 명시=즉시 · 신호=한 번 묻기 · 요약·번역·단일 사실 조회=비발동 |

## 단언

잘린 재료(표 선행 · ❌ 표시 · 이어 읽기)(3) · 자기해독(표 안 확인 · 미등재 인용 0)(2) · 결정(전환 명시 · 추천+이유 · 비교표 없음)(3) · 딥다이브(등재 · 복귀)(2) — 총 10. 발동은 12 질의 발동/비발동 일치 수.
