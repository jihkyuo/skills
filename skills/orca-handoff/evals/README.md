# evals

이 스킬은 **라우팅 순간**(사용자 문장이 이 스킬·경합 스킬·확인 질문 중 어디로 가는가)과 **판단 두 지점**(갈래 판별·전달 확인)을 시나리오로 잘라 검증한다. 실행자는 스킬 파일만 읽고 답하며(터미널 생성·워크트리 조작 금지), 채점은 아래 기대와 대조한다.

실제 핸드오프는 살아 있는 Orca 앱·워크트리에 묶여 있어 **레포에서 재현하지 않는다.** 실전 리허설은 다음 실제 핸드오프에서 하고, 밟힌 지뢰를 SKILL.md 에 반영한다.

## 시나리오 (형태)

| 시나리오 | 상황 | 유혹 | 기대 |
|---|---|---|---|
| 라우팅 5문 | «핸드오프해줘» / «핸드오프 문서만 만들어줘» / «orca terminal create 어떻게 써?» / «/handoff» 명시 / «codex 한테 넘기고 끝나면 알려줘» | 전부 이 스킬로 받기 | orca-handoff / 문서 단계만·터미널 없음 / orca-cli / 명시 호출한 그 스킬 / 확인 질문(핸드오프인지 오케스트레이션인지) |
| 갈래 판별 | 브랜치에 미push 커밋 12 + untracked 3 | 깨끗한 독립 워크트리 | 같은 워크트리에 새 터미널 (새 워크트리는 그 브랜치 로컬 상태가 시야에 없다) |
| 미제출 | `terminal read` 에 `❯` 뒤 프롬프트 글자 + $0.00 | 완료 대기 · 새 터미널 재스폰 | `terminal send --enter` 1회 → 재확인 → 그래도 미기동이면 터미널 보존한 채 보고·중단 |
| 문서 슬롯 | 오케스트레이션 런 도중 핸드오프 | «마지막 보고 참조» 한 줄 | 슬롯 10 전부 · 대화 참조 0 · 콜드 리더 5문에 명령·파일 수준 답 |
